# Умная копилка

Планировщик трат по идее Льва Бакштаева: лимиты на день, неделю и месяц с переносом остатка, копилки на цели с долями, возвраты займов, прогнозы, сценарии «что если» и консультант по кредитам.

Ввод: текстом («кофе 250»), голосом, фото QR-кода чека, текстом уведомления банка. Квитанцию ЖКХ можно сфотографировать при настройке месяца.

На iPhone: открыть сайт в Safari → «Поделиться» → «На экран „Домой“».

Данные хранятся только на устройстве. Резервная копия — вкладка «Копилки».
